Smart Surveillance System

An AI-driven security platform that turns raw CCTV streams into real-time threat detection — fire, smoke, intrusion — with live monitoring, alerting, and dispatch. I led the UX redesign from a v1 prototype into a full bilingual high-fidelity system across web and mobile.

Overview

Smart Surveillance System (SSS) is an AI-driven security solution that watches CCTV camera streams and flags threats in real time — fire, smoke, intrusion — using on-device detection and multimodal vision analysis. It gives security teams a live map of every camera, an alert center, history and reporting, and a dispatch flow for patrol response.

I led the UX from a rough v1 prototype through a full redesign: information architecture, wireframes, and a high-fidelity, bilingual (EN/KO) system across web and mobile. The redesign reframed a single crowded "dashboard" into focused workspaces — Live Monitoring, History & Reports, Device & Map Management, and a mobile Dispatch Inbox.

Outcome

SSS matured from an AI-detection prototype into a coherent, bilingual (EN/KO) surveillance product spanning web and mobile — real-time map monitoring, an alert center, history and heat-map reporting, device and user management, and a field Dispatch Inbox. The redesign turned a dense engineering demo into an operator-ready tool, and was implemented in Next.js.
